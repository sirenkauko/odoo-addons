# Odoo Addons

A collection of community modules and productivity enhancements for Odoo by Kauko Sirén.

## Available Modules

| Module | Version | Description |
| :--- | :--- | :--- |
| **[chatter_toggle](chatter_toggle/)** | 20.0 | Toggle button to show or hide the chatter panel in form views, expanding form sheets to 100% width. |

## Installation

Clone this repository into your Odoo addons path:

```bash
git clone -b 20.0 https://github.com/sirenkauko/odoo-addons.git
```

And add the path to `addons_path` in your `odoo.conf`:

```ini
addons_path = /path/to/odoo/addons,/path/to/odoo-addons
```
