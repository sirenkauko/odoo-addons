Sale Quotation Merge for Odoo 20

Consolidate and merge multiple draft sales quotations into a single quotation with one click.

Odoo 20 Compatible Smart Line Merging Full Chatter Traceability English & Finnish

The Problem

Customers frequently request multiple separate quotes or ask to add products over several phone calls or emails. Standard Odoo does not have a native feature to merge these quotations, forcing sales teams to manually re-type lines and recalculate subtotals.

The Solution

Sale Quotation Merge adds a streamlined Merge Quotations action directly to the Quotations list view. Simply select two or more draft quotations for the same customer and merge them into a single comprehensive quotation instantly.

Key Features

Flexible options designed for everyday sales workflows.

Flexible Target Selection

Choose which quotation acts as the master target order. All lines from the other quotations are transferred to it.

Optional Line Consolidation

Keep lines separate or sum up quantities for identical products sharing the same unit price, taxes, and discounts.

Full Chatter Traceability

Automatic chatter logging on both source and target quotations ensures complete audit trail and easy cross-referencing.
